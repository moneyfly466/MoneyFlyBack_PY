# MoneyFly  
### Control inteligente de gastos hormiga con análisis de datos

---

## 📌 Descripción

**MoneyFly** es una solución educativa diseñada para ayudar a las personas a identificar, analizar y controlar sus *gastos hormiga* mediante el uso de análisis de datos.

El proyecto integra:

- 🐍 **Python (Pandas)** para procesamiento y análisis de datos  
- ⚛️ **React** para la interfaz de usuario  
- ☕ **Spring Boot** para el backend y la gestión de servicios  

El objetivo principal es transformar pequeños gastos cotidianos en información valiosa que permita tomar decisiones financieras más inteligentes.

---

## 🎯 Objetivos del proyecto

- Identificar patrones de gasto invisibles a simple vista  
- Clasificar gastos automáticamente  
- Generar insights financieros personalizados  
- Promover la educación financiera mediante datos  

---

## 🧠 Tecnologías utilizadas

- 🐍 Python  
- 📊 Pandas  
- ⚛️ React  
- ☕ Spring Boot  
- 🗄️ (Opcional) Base de datos relacional o NoSQL
